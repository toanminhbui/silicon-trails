# Implementation contract

## RTL frontend

`src/rtl/compiler.js`: `compileVerilog(source, {top = "top"} = {})` returns a Promise of `{netlist, hierarchy, log, top, source}`. `netlist` is a flattened, word-level Yosys JSON netlist. `hierarchy` is pre-flatten Yosys JSON preserving modules. Real Yosys runs in a Web Worker; Node entry for tests and generating examples can call the same synthesis helper without a Worker. Browser uses bundled, locally served toolchain assets, no server or external synthesis request. Failures are errors with readable diagnostics.

`src/rtl/examples.js`: exports `RTL_EXAMPLES`, array of `{id, name, description, source, top, inputs}`; includes complete CPU and accumulator, full adder, counter. `public/examples/cpu.json` is compiled result for instant default load. Source/compiled fixtures generated by `scripts/generate-examples.mjs`.

## Circuit simulation

`src/core/simulator.js`: exports `CircuitSimulator`. Constructor `(netlist, {top} = {})`; properties `module`, `cycle`, `diagnostics`; methods `setInput(name, numberOrNull)`, `getPort(name)`, `getBits(bits)`, `getCellPorts(id)` -> port values, `settle()`, `tick()` (one shared rising edge, simultaneous state commit), `reset()`, `snapshot()`, `restore(snapshot)`. Numbers are unsigned; null is unknown. Reject unsupported cells and invalid multiple drivers. Handle 32-bit buses and signed operations correctly or explicitly reject.

`src/core/assembler.js`: exports `assemble(text)` -> `{words, listing}`, `disassemble(word)`, `PROGRAMS` array `{id,name,description,source}`. Instructions fixed 16 bits `[opcode8 | operand8]`: NOP=0, LDI=1, LOAD=2, STORE=3, ADD=4, ADDI=5, SUBI=6, JMP=7, JZ=8, JNZ=9, HALT=255. Hex literals, decimal, labels, semicolon comments. Arithmetic wraps 8 bits.

`src/core/cpu-lab.js`: `CpuLab(netlist, {latency=3, cache=false}={})`; owns `.sim`, `.ram` 256-byte Uint8Array, `.events` memory event list, `.trace` retirements, `.cycle`, `.halted`, `.display`, `.cacheStats`, `.cacheLines`; methods `loadProgram(text)`, `stepClock()`, `stepInstruction(maxClocks=1000)`, `reset()`, `rewind()`, `getState()` -> `{a,pc,ir,z,c,state,cycle,halted,display,pending}`. Runtime feeds actual circuit ports, not an ISA interpreter. Request acceptance and response completion distinct. Stores commit once at response handshake. Address FE numeric display (uncached), FF input (uncached; input default 0). RAM resets to initial zero image. Cache optional direct mapped four lines × four bytes, write-through/no-write-allocate. Independent reference tests check results.

### CPU top interface (Verilog module top)

Inputs: `clk`, `reset`, `instruction[15:0]` (asynchronous program ROM indexed by output PC), `mem_ready`, `mem_resp_valid`, `mem_rdata[7:0]`. Outputs: `pc[7:0]`, `a[7:0]`, `ir[15:0]`, `z`, `c`, `state[3:0]`, `mem_valid`, `mem_write`, `mem_addr[7:0]`, `mem_wdata[7:0]`, `mem_resp_ready`, `retired`, `retire_pc[7:0]`, `halted`, `fault`.

Instruction fetch latches IR and advances PC in FETCH phase. No program-memory handshake in v1 (asynchronous ROM). EXEC retires immediate/branch/HALT; memory instructions transition DATA_REQ then DATA_WAIT, retiring on response handshake. `retired` is combinational pre-edge event; wrapper samples it before tick. LDI and LOAD update Z, preserve C; ADD/ADDI update Z/C (overflow); SUBI updates Z/C (no borrow); stores/branches preserve flags.

## Reusable construction modules

`src/ui/builder.js` exports `CircuitBuilder` and `BUILDER_TYPES`. The primitive library contains 16 types. Custom instances use `{id,type:"module",moduleId,label,position}` and refer to immutable definitions saved in the builder.

- `previewModule(nodeIds)` infers the selected root subcircuit’s boundary. Its `.ports` entries contain `{name,direction,width,key,bindings}`. Root Input, Switch, and Output blocks cannot be selected for packaging.
- `createModule({name,nodeIds,portNames:{oldName:newName}})` validates and packages the selection, returning `{moduleId,instanceId}`. It reconnects the selection’s existing external cables through the new instance. The default registered-adder boundary names are `add1_A`, `add1_B`, `register1_EN`, and `register1_Q`.
- `addModule(moduleId,position)` places another instance. `listModules()` returns detached definitions with IDs, names, ports, functional nodes, edges, and node counts.
- `getDesign({path:instanceIdArray})` returns a scoped visual graph. Internal nodes have absolute slash-separated IDs, a `localId`, and live bit/cell bindings. Module nodes carry their `instancePath`.
- `getInstancePorts(path)` returns the instance’s typed ports with actual root-simulator `.bits`. `getDefinitionForPath(path)` resolves its immutable definition.

The runtime expands instances into one flattened circuit with distinct registers for every instance and one shared clock. `toVerilog()` emits hierarchical definitions and instances. `toJSON()` keeps version 1 with an optional `modules` array, so older primitive-only constructions remain readable. Definitions must form a finite acyclic dependency graph; missing/recursive references, invalid boundary mappings, unsupported expansion, and ordinary circuit errors are rejected.

Topology changes restart Builder execution. Opening or closing a module only changes the graph view and retains the same `CircuitSimulator`, clock, registers, and rewind history. Internal views are read-only. The main debug API reports the active path as `getGameState().builderPath`; `game.builderView` can persist that inspection path. Checkpoints retain all nested instance registers. See [the module walkthrough](reusable-modules.md).

## Spatial renderer

`src/world/world.js` exports `CircuitWorld`, constructor `(container, {onSelect, onConnect, onPlace, onPause, onMove, onTarget}={})`. Methods `setDesign({nodes,edges})`, `updateSignals({nodeValues,edgeValues})`, `select(id)`, `focus(id)`, `teleportToNode(id)`, `resetCamera()`, `setMode("orbit"|"walk"|"build")`, `setTool(typeOrNull)`, `setPaused(boolean)`, `dispose()`. The compatible `walk` mode and `startWalk({reset,lock})` entry now use unconstrained free flight. WASD follows camera orientation; Space rises, Q/C descends, Shift boosts. Each node `{id,label,type,kind,width,position?:[x,y,z],ports?:[{name,direction,width}],source?,scope?}`. Each edge `{id,from,to,fromPort?,toPort?,label?,width?}`. Values maps id → number/null or `{value,active}`. Callbacks selection `(id)`; connection `({from,fromPort,to,toPort})`; placement `({type,position})`. Renderer includes responsive sizing, raycast selection, orbit exploration, and live signal labels. Node positions optional: auto-layout when absent. No DOM UI outside canvas container.

Viewing methods are `setLayoutScale(number)`, `setComponentScale(number)`, `setPartScale(id,number)`, `getViewSettings()` → `{layoutScale,componentScale,partScales}`, and `applyViewSettings(settings)`. All defaults are one. Layout scale clamps to 0.35–3; component and individual scales clamp to 0.4–3. The UI layout slider starts at 0.5. Body scale multiplies the global component scale by its individual override. Layout scaling multiplies the original component position, never the already scaled position. Ports, wires, selection, and focus use transformed positions. These operations never change the simulator or advance a clock. Projects store settings in `game.viewSettings`.

## Out-of-order teaching model

`src/core/ooo-lab.js` exports `OoOLab` and `OOO_PROGRAMS`. This is a separate high-level cycle model, not a Yosys netlist or ST-8 instruction interpreter. Constructor options are `{source,robSize=12,rsSize=8,lsqSize=6,physicalCount=24,mulLatency=5,memoryLatency=3,onChange}`. It has eight 8-bit architectural registers, a constant-zero R0, two-wide in-order dispatch/retirement, one ALU, one multiply unit, and one load/store unit.

Methods: `loadProgram(source)`, `stepClock()`, `stepInstruction(maxClocks=1000)`, `reset()`, `rewind()`, `getState()`, `snapshot()`, and `restore(snapshot)`. The model exposes `.program`, `.ram`, `.events`, `.lastEvents`, `.trace`, `.cycle`, `.halted`, and `.display`. `getState()` returns detached register maps/values, physical readiness, the free list, ROB, reservation stations, LSQ, units, counters, and latest events. The complete CPU state and program/configuration are versioned in `game.architecture`; navigation scale is separate. Rewind retains up to 256 clocks; persisted logs retain up to 512 entries and do not include rewind history.

Supported assembly: `LI`, `ADD`, `SUB`, `MUL`, `ADDI`, `LOAD`, `STORE`, `NOP`, `HALT`. There are no branches, prediction/recovery, architectural exceptions, or coherence. Memory ordering conservatively waits for unknown older store addresses and forwards from the youngest matching older store when ready. Stores emit `memory-write` only at in-order retirement. See [the architecture guide](processor-architecture.md) for timing and examples.

`src/ui/ooo-overview.js` maps named components and model events into a world graph. `src/ui/architecture-panel.js` renders the actual model state as pipeline/inspector tables. `window.siliconTrails.getArchitectureLab()` exposes the active teaching model for debugging. Its state remains separate from `getLab()` and `getSimulator()` used by synthesized hardware.
